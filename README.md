# **Oasis Infobyte Data Science Internship Projects**

This repository showcases the Data Science projects completed during my internship with **Oasis Infobyte**. Each project focuses on solving real-world problems using data analysis, visualization, and machine learning techniques in Python.

---

## **Task 1: Iris Flower Classification**

**Field:** Supervised Machine Learning – Classification
**Description:**
This project focuses on predicting the species of iris flowers (**Setosa, Versicolor, Virginica**) based on their sepal and petal dimensions. It uses labeled data to train classification models.

**Data Science Concepts Applied:**

* Data preprocessing
* Data visualization using seaborn & matplotlib
* Model training using logistic regression & decision trees
* Model evaluation using accuracy score and confusion matrix

**Tools Used:** Python, Pandas, Scikit-learn, Seaborn, Matplotlib


---

## **Task 3: Car Price Prediction**

**Field:** Supervised Machine Learning – Regression
**Description:**
This project involves predicting car prices using attributes like brand, engine specs, mileage, and horsepower. It applies regression algorithms to estimate the selling price.

**Data Science Concepts Applied:**

* Data cleaning and feature engineering
* Correlation analysis & multivariate regression
* Data visualization (heatmaps, pairplots)
* Model evaluation using R² score and MAE

**Tools Used:** Python, Pandas, NumPy, Scikit-learn, Seaborn


---

## **Task 5: Sales Prediction**

**Field:** Predictive Modeling in Business Analytics
**Description:**
This project predicts product sales based on advertisement budgets across TV, Radio, and Newspaper platforms. It helps analyze how marketing strategies impact product demand.

**Data Science Concepts Applied:**

* Exploratory Data Analysis (EDA)
* Linear regression modeling
* Feature-target relationship visualization
* Model performance evaluation using RMSE and R² score

**Tools Used:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn
